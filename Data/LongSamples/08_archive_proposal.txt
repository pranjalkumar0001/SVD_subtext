Library Archive Digitisation Proposal

The college library holds a collection of old newsletters, student magazines, meeting records, and photographs that are difficult to search in their current paper form. Readers usually depend on a librarian remembering where a particular item is stored. The proposed archive project will create digital copies and a searchable catalogue while preserving the original material. The first stage will focus on a small collection whose ownership and permission status can be checked before scanning begins.

Each item will receive a stable identifier that links the original document, its scanned images, and its catalogue entry. The catalogue should record a title, approximate date, creator when known, document type, and a short description. Missing information must remain explicitly unknown rather than being guessed. A magazine with an uncertain publication year should not acquire a precise date merely because a nearby folder has one. Volunteers will keep notes explaining where each description came from.

Scanning quality matters because a poor digital copy may become the only version that future readers encounter. Pages should be checked for cropping, rotation, blurred text, and missing edges. Fragile bindings require careful handling and may need a different scanning method. Optical character recognition can produce searchable text, but the resulting words must be reviewed, particularly when pages contain unusual fonts, columns, handwriting, or damaged print. The scanned image remains the visual reference for correcting transcription errors.

Search will initially use catalogue fields and the recognised text. A reader looking for a sports event may search by title, year, or a phrase appearing in an article. Different spellings and incomplete descriptions can make relevant records difficult to retrieve. A small controlled list of subject terms could improve consistency, although it should not replace the original wording. The project will retain both the source text and any later corrections so that changes can be traced.

Access rules must be decided before the collection is placed online. Some records may contain personal contact details or material that was never intended for public distribution. The library should identify which items can be openly viewed and which require restricted access. Possession of a physical magazine does not automatically settle permission to publish every photograph inside it. Uncertain cases should be reviewed rather than silently included in the public collection.

The pilot will be evaluated using a set of search tasks prepared by library staff. Reviewers will try to locate known articles and check whether catalogue entries lead to the correct pages. The evaluation will record missing metadata, transcription mistakes, and failed searches. A successful pilot should make the collection easier to discover while preserving clear provenance, reliable identifiers, and a practical process for correcting errors.
